# 🍔 Максимально простое бургер-меню (Simple Burger Menu)

Это легкий, понятный и максимально простой пример реализации адаптивного бургер-меню для сайта. Проект идеально подходит для новичков, которые хотят разобраться, как связать HTML, CSS и JavaScript для создания базовой анимации.

## 🚀 Особенности проекта
* **Минимум кода:** Никаких тяжелых библиотек или фреймворков. Только чистый (Vanilla) JS и CSS.
* **Плавная анимация:** Кнопка плавно трансформируется в крестик, а меню элегантно выезжает справа.
* **Адаптивность:** Меню фиксировано по высоте экрана (`100vh`) и аккуратно смотрится на любых смартфонах.
* **Без лишнего скролла:** Использовано скрытие горизонтальной прокрутки, чтобы страница не дергалась при открытии.

## 🛠️ Стек технологий
* **HTML5** — базовая разметка структуры и ссылок.
* **CSS3** — стилизация, позиционирование (`position: fixed`) и плавные переходы (`transition`).
* **JavaScript** — всего одна функция `toggle()`, которая отвечает за переключение классов анимации по клику.

## 📂 Структура кода

Логика работы построена на трех китах:
1. **HTML:** Создается кнопка `.burger-btn` с тремя линиями внутри и блок меню `.mobile-menu`.
2. **JS:** При клике на кнопку JavaScript находит элементы и переключает у них класс `.open`.
3. **CSS:** Как только добавляется класс `.open`, CSS плавно меняет координату `right: -300px` на `right: 0` для меню, а линии кнопки поворачивает на 45 градусов, превращая в крестик.
