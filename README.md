# ⚡️ Cyberpunk Burger Menu (Полукруглое неоновое меню)

Экспериментальная модификация нашего адаптивного бургер-меню, выполненная в ярком футуристичном стиле **Cyberpunk**. Базовая логика JavaScript осталась прежней, но внешний вид и анимация были полностью переработаны с использованием продвинутых возможностей CSS.

## 🌌 Визуальные фишки этой ветки
* **Эффект жидкого полукруга:** В скрытом состоянии левая грань меню выгнута в идеальную дугу благодаря сложной геометрии `border-radius`. При выезде шторка плавно расправляется.
* **Неоновое свечение:** Кнопка-бургер и ссылки подсвечиваются мягким бирюзовым и пурпурным градиентом (`box-shadow` и `text-shadow`).
* **Каскадный вылет ссылок:** Пункты меню не появляются одновременно — они красиво вылетают один за другим с нарастающей задержкой (`transition-delay`).
* **Исправленные слои:** Кнопка зафиксирована на уровне `z-index: 1001`, благодаря чему она всегда остается доступной поверх выезжающей панели для быстрого закрытия.

## 📂 Изменения в структуре
Вместо базовых стилей в этой ветке используется файл **`modern-style.css`**. 

Чтобы проект отображался корректно, убедитесь, что в вашем `index.html` подключен именно он:
```html
<link rel="stylesheet" href="modern-style.css">
```

## 🛠️ Как это работает в CSS?
1. **Форма дуги:** Создана с помощью раздельных радиусов скругления через косую черту: `border-radius: 0 100% 100% 0 / 0 50% 50% 0;`.
2. **Плавный вылет:** Использование таймингов для каждого дочернего элемента списка:
   ```css
   .menu-links li:nth-child(1) { transition-delay: 0.2s; }
   .menu-links li:nth-child(2) { transition-delay: 0.3s; }
   ```

Эта ветка показывает, как на одном и том же HTML-каркасе и минимуме JS можно создавать кардинально разные интерфейсы за счет прокачки CSS-стилей!
